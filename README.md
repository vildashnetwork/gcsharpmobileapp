# GC Sharp — AI-Powered Social Learning Platform

GC Sharp (`com.gcsharp`) is a mobile learning platform for Cameroon students
(GCE O Level / A Level, HND, Concours) built on **FastAPI + MongoDB + Expo
React Native**, upgraded in place into an AI-powered social learning platform
whose educational content is generated by **GC Sharp's own backend model**.

## What's inside

| Area | Where | Summary |
|---|---|---|
| Learning Feed (Phase 1) | `backend/gc_feed.py`, `frontend/app/(tabs)/feed.tsx`, `frontend/app/feed/*` | Students post questions with images/short videos; comments + replies, likes, saves, shares; search + filters (subject/topic/exam level/type); cursor pagination with loading/error/retry states |
| GCSharp model (Phase 2) | `backend/gc_model.py` | The ONLY runtime generator for tutor answers, explanations, exam questions and video scripts. OpenAI-compatible HTTP (`GC_MODEL_URL`) or local GGUF (`GC_MODEL_PATH`). **No external LLM fallback** — clear HTTP 503 + Retry when down. See `backend/DEPLOY_GCSHARP_MODEL.md` |
| Knowledge growth (Phase 3) | `backend/gc_knowledge_growth.py` | APScheduler pipeline: mine topics → search trusted sources → score quality → GCSharp model writes the explanation → store in `ai_knowledge` with full provenance. Available to retrieval immediately (no retraining) |
| Training (Phase 4) | `backend/gc_training.py` | Separate, manual, controlled pipeline: curated datasets (verified knowledge + reviewed teacher feedback only), validation, evaluation, checkpoints, rollback metadata. Honest capability reporting |
| Real-time (Phase 5) | `ConnectionManager`, `/api/ws/learning`, `/api/realtime/events` | Multi-socket-per-user manager; JWT-authenticated learning channel; persistent event log replayed on reconnect |
| Push reliability (Phase 6) | `send_expo_push`, `create_notification` | Retry with backoff, duplicate suppression, invalid-token cleanup, notification history + read/unread + badge count |
| Video generation (Phase 2) | `/api/papers/{id}/video`, `/api/papers/{id}/video/highlight`, `/api/ai/video/from-text`, `/api/ai/video/from-pdf` | PDF-to-video and text-to-video lesson scripts generated by the GCSharp model (heading / whiteboard / narration scenes) feeding the existing TTS + audio cache + player |
| Tests (Phase 8) | `backend/tests/test_gcsharp_upgrades.py` | Offline tests: model adapter against a local mock server, strict no-fallback behavior, feed upload validation (MIME + magic bytes), rate limits, source scoring, training honesty, route wiring |

## Quick start

```bash
# Backend
cd backend
pip install -r requirements.txt
cp .env.example .env      # then set GC_MODEL_URL or GC_MODEL_PATH
python server_sqlite_full_corrected.py

# Tests
python -m pytest tests/test_gcsharp_upgrades.py -v

# Frontend
cd ../frontend
npm install
npx expo start
```

## Model configuration (required for AI features)

Set **one** of these in `backend/.env` (full guide: `backend/DEPLOY_GCSHARP_MODEL.md`):

```bash
GC_MODEL_URL=http://localhost:11434/v1   # Ollama / llama.cpp / vLLM / LM Studio
# or
GC_MODEL_PATH=/abs/path/gcsharp.gguf     # in-process llama-cpp-python
```

Check it: `GET /api/ai/model/status?probe=1`

## Key API surface (new)

```
POST   /api/feed/posts                     create post (text + meta)
POST   /api/feed/posts/{id}/media          image/short-video upload
GET    /api/feed/posts                     list/search/filter (cursor)
GET    /api/feed/posts/{id}                detail + threaded comments
POST   /api/feed/posts/{id}/like|save|share
POST   /api/feed/posts/{id}/comments       comment or reply
POST   /api/feed/posts/{id}/ai/retry       re-run GCSharp explanation
GET    /api/ai/model/status                model config/health
POST   /api/ai/video/from-text             text/topic -> video lesson
POST   /api/ai/video/from-pdf              uploaded PDF -> video lesson
WS     /api/ws/learning?token=<jwt>        authenticated real-time channel
GET    /api/realtime/events?since=<iso>    missed-event recovery
GET    /api/ai/knowledge/growth/status     knowledge pipeline observability
POST   /api/ai/knowledge/growth/run        manual bounded ingest pass (staff)
GET    /api/ai/training/status|runs|checkpoints
POST   /api/ai/training/run                controlled training run (staff)
```

## Ground rules honoured by this codebase

1. The GCSharp model — and only it — generates educational content at runtime.
2. New verified knowledge is retrievable immediately; training never runs inside
   a student request and never auto-fires on unreviewed data.
3. Citations shown in the app come from real search results; nothing is
   fabricated, and conflicting sources are recorded, not overwritten.
4. Existing features (past papers, PDF viewer, AI tutor, lesson videos,
   accounts, progress, notifications, study groups) keep working — upgrades
   were made in place.
